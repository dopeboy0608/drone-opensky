# 스펙: 국토부 쌓임 순서 상수 분리 (#112, 스토리 #110)

## 배경/목적

겹친 구역의 색 쌓임은 국토부 원스톱과 같아야 한다. 원스톱 지도 객체(`vmap.getLayers()`, 2026-11-23 확인)에서
그려지는 순서를 읽어 보니 비행금지가 비행제한·UA보다 아래에 깔린다. 반면 우리 `ZONE_TYPES` 배열 순서는
클릭 겹침 판정(위험도 순, 비행금지 최상위)과 WMS 쌓임에 함께 쓰인다. 두 순서의 의미가 다르므로 쌓임용 순서를
별도 상수로 분리한다. 적용(WMS·폴리곤)은 #113에서 한다.

## 입력

- **`LAYER_STACK_ORDER`**: 우리 12종 typename을 바닥 → 위 순서로 나열한 상수 (`constants.ts`).

## 기대 동작

- [ ] 12종 typename을 모두 한 번씩 포함한다(`ALL_ZONE_TYPENAMES`와 같은 집합).
- [ ] 원스톱 순서를 따른다: 경계구역 → 관제권 → 비행금지 → 비행장교통 → 비행제한 → (군작전구역, 임시) → UA → 경량항공기 → 위험 → 임시비행금지 → 국립자연공원 → 드론시범사업.
- [ ] 비행금지가 비행제한과 UA보다 아래에 있다(원스톱과 같은 동작).
- [ ] 클릭 판정 순서(`ALL_ZONE_TYPENAMES`, 비행금지 최상위)는 그대로다. 두 순서는 서로 다르다.

## 엣지케이스

- [ ] 군작전구역(`lt_c_aismoac`)은 원스톱 레이어에 없어 위치가 미정이다. 비행제한구역 바로 위에 임시로 두고 주석으로 확인 필요를 표시한다.
- [ ] 원스톱의 범위 밖 레이어(`lt_c_aispca`, `lt_c_aisobls`, `lt_c_uo301`, `lt_c_ademd`, `lt_c_aisport`)는 순서에서 제외한다.
