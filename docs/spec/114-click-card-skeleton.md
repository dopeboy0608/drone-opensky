# 스펙: 클릭 안내 카드 즉시 노출과 스켈레톤 (#114, 스토리 #110)

## 배경/목적

클릭하면 지점에 스피너(`AirspaceClickPending`)만 보이다가 구역이 확정된 뒤에야 카드가 뜨고, 카드 안의 주소는 또 늦게 채워진다.
클릭 즉시 카드를 띄우고, 아직 모르는 항목은 스켈레톤으로 자리를 잡아 도착하는 대로 채운다. 스피너는 없앤다.

## 입력

- **`SelectedZone.isPending`**: `true`면 구역 조회 중인 카드다(`zoneType`은 아직 없음).
- **`useAirspaceMapInteraction`의 `selectedZone`**: 조회 중이면 클릭 좌표의 대기 카드(`isPending: true`)를, 아니면 확정된 구역을 준다.
- **`AirspaceZoneOverlay`**: `isPending`을 받고, 주소 상태(`loading`)를 스켈레톤으로 그린다.

## 기대 동작

- [ ] 클릭(조회 시작) 즉시 클릭 좌표에 카드가 열린다. 카드는 제목, 구역 태그, 안내 띠, 하단 주소의 스켈레톤을 가진다.
- [ ] 구역이 확정되면(`onProgress` 또는 완료) 대기 카드가 확정 카드로 바뀐다. 같은 위치라 카드가 다시 자라나는 효과를 재생하지 않는다.
- [ ] 주소가 아직 조회 중이면 제목과 하단 주소가 스켈레톤이고, 도착하면 텍스트로 바뀐다. 제목에서 "주소 조회 중…" 문구는 없어진다.
- [ ] 클릭 지점의 스피너(`AirspaceClickPending`)는 제거한다.
- [ ] 접근성: 대기 카드는 `role="status"`와 "구역 조회 중" 이름을 가진다.
- [ ] 카드 폭(w-60)과 앵커 구조(0×0 루트)는 바뀌지 않는다.
- [ ] 새 클릭이 오면 이전 카드 대신 새 위치의 대기 카드가 열린다.

## 엣지케이스

- [ ] 조회가 실패하면 대기 카드는 닫히고 기존 오류 토스트가 뜬다.
- [ ] 조회 중에 표시 방식을 바꾸면 대기 카드가 열려 있지 않는다(기존 조회 취소 동작 유지, #94).
- [ ] 구역이 없으면 기존처럼 "조회된 규제 구역 없음" 카드로 바뀐다(대기 카드가 그대로 남지 않는다).
- [ ] 주소 조회가 실패하면 기존 오류 문구를 그대로 쓴다(스켈레톤이 남지 않는다).
- [ ] 스켈레톤 애니메이션은 `prefers-reduced-motion`에서 멈춘다.
