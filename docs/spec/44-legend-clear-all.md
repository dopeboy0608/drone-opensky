# 스펙: 범례 전체 해제/전체 선택 버튼 (#25 서브태스크 03, #44)

## 배경/목적

필터 패널에서 12종을 한 번에 끄고(전체 해제), 모두 꺼진 상태에서는 같은 버튼이 "전체 선택"으로
바뀌어 한 번에 복구할 수 있게 한다. 요구사항 기준은 이슈 #25 본문 FR-003.

## 입력

- **`setAllZones(isVisible)`**: 모든 typename을 한 번에 같은 값으로 설정하는 스토어 액션.
- **버튼 클릭**: 하나라도 켜져 있으면 "전체 해제", 모두 꺼져 있으면 "전체 선택".

## 기대 동작

- [ ] `setAllZones(false)`는 12종 모두 `false`로 만든다.
- [ ] `setAllZones(true)`는 12종 모두 `true`로 되돌린다.
- [ ] 키 집합은 바뀌지 않는다(새 키를 만들지 않는다).
- [ ] 하나라도 켜져 있으면 버튼 문구가 "전체 해제"이고, 클릭하면 모두 끈다.
- [ ] 모두 꺼져 있으면 버튼 문구가 "전체 선택"이고, 클릭하면 모두 켠다.
- [ ] 모두 꺼진 지도는 빈 지도이며 별도 안내는 없다.

## 엣지케이스

- [ ] 일부만 꺼진 상태에서 "전체 해제"를 눌러도 모두 꺼진다.

## 범위 밖

- 색상/패턴 변경, 멀티폴리곤 토글, localStorage 저장.
