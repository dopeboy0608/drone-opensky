# 스펙: 범례 필터 패널 UI + 토글 스토어 (#25 서브태스크 01, #42)

## 배경/목적

공역 12종(typename)을 개별로 지도에서 켜고 끌 수 있게 하는 필터의 첫 단계. 이 서브태스크는
패널 UI와 토글 상태 스토어까지만 만들고, 지도 반영은 #43에서 한다. 요구사항 기준은 이슈 #25 본문.

## 입력

- **토글 액션**: `toggleZone(typename)` — 사용자의 체크박스 클릭 이벤트.
- **초기 상태**: `TYPENAME_ZONE_LABELS`의 12개 typename 전부 `true`.
- **패널 열기/닫기**: 좌측 하단 "범례" 버튼 클릭 (컴포넌트 로컬 상태).

## 기대 동작

- [ ] 스토어 초기값은 12종 모두 `true`(켜짐)다.
- [ ] `toggleZone(typename)`은 해당 typename만 반전하고 나머지는 그대로 둔다.
- [ ] 같은 typename을 두 번 토글하면 원래 값으로 돌아온다.
- [ ] 패널은 금지/제한/가능 3그룹으로 나눠 12종 체크박스를 보여주고, 그룹 색상 표시와 `TYPENAME_ZONE_LABELS` 라벨을 쓴다.
- [ ] 체크박스 변경이 스토어에 반영되고, 패널을 닫았다 열어도 유지된다.
- [ ] 지도 표시는 이 단계에서 바뀌지 않는다.

## 엣지케이스

- [ ] 알 수 없는 typename으로 `toggleZone`을 호출해도 상태가 바뀌지 않는다(키가 새로 생기지 않는다).
