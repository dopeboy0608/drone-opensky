# 스펙: 구역 안내 박스 제목 간소화와 전체 주소 표시

## 배경/목적

안내 박스 제목이 주소 전체(예: `서울특별시 관악구 보라매로5길 15`)라 폭 240px 카드에서 말줄임이 된다. 시·도, 시·군·구는
지도를 보면 알 수 있는 정보이므로 제목에서는 상세 주소만 남기고, 전체 주소는 카드 맨 아래 줄에 줄바꿈해 보여 준다.

## 입력

- **`stripRegionPrefix(address)`**: 순수 함수. 주소 문자열에서 맨 앞의 시·도와 시·군·구 토큰을 제거한다.
- **`formatZoneAddressTitle(state)`**: 성공 시 `stripRegionPrefix(primary)`를 준다.
- **`formatZoneAddressFull(state)`**: 성공 시 전체 주소(`primary`)를 준다. 그 외 null.

## 기대 동작

- [ ] 시·도는 약칭(`서울`, `경기`)과 정식 명칭(`서울특별시`, `경기도`, `강원특별자치도`, `세종특별자치시`)을 모두 제거한다.
- [ ] 시·도 뒤의 시·군·구 토큰을 이어서 제거한다. `수원시 영통구`처럼 시 아래 구가 이어지면 둘 다 제거한다.
- [ ] 도로명이면 `도로명 건물번호`, 지번이면 `동 번지`(예: `신림동 1452-29`)가 남는다.
- [ ] 제목 말줄임은 남은 상세 주소가 그래도 길 때만 생긴다. 제목 속성(title)에는 전체 주소를 둔다.
- [ ] 카드 맨 아래 줄에 전체 주소를 보여 주고 줄바꿈한다. 도로명 주소의 지번은 그 아래에 `지번 …`으로 둔다.
- [ ] 조회 중에는 아래 줄 높이를 확보해 결과가 도착해도 카드가 움직이지 않는다(기존 동작 유지).

## 엣지케이스

- [ ] 제거하면 아무것도 남지 않으면(`서울특별시`만 있는 경우) 원문을 그대로 쓴다.
- [ ] 행정구역만 있는 주소(`서울특별시 종로구 청운효자동`)는 `청운효자동`이 된다.
- [ ] 시·도 토큰이 없는 문자열은 바꾸지 않는다.
- [ ] 도로명 이름이 `구`·`시`로 끝나도(예: 지번 `시흥동`은 `동`이라 해당 없음) 시·도 뒤 연속 토큰만 제거하므로 중간 토큰은 건드리지 않는다.
- [ ] 주소 조회 상태가 loading/notFound/error/idle이면 기존 문구 그대로다.

## 범위 밖

- 주소 조회 방식(`reverseGeocode`) 변경
- 안내 박스 폭 변경
