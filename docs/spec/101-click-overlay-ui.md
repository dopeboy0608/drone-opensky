# 스펙: 클릭 오버레이 UI 개선

## 배경/목적

클릭 안내 카드(#27)에서 최상위 구역은 제목에, 겹친 구역은 별도 줄에 있어 한눈에 비교되지 않는다. 이슈 #101의 요청과 사용자가 확정한 추천안(2026-11-17)에 따라 `[클릭 공역] [겹침1] [겹침2]…` 형태로 태그를 이어 표기하고 나머지 정보의 시각 표기를 정리한다.

## 입력

- `SelectedZone` (`zoneType`, `overlap`), 주소 조회 상태(`AddressState`), 범례 숨김 여부(`isHidden`) — 모두 #27에서 이미 제공됨. 데이터 변경 없음.

## 기대 동작

- [ ] 태그 줄: 최상위 구역 태그를 첫 번째에 진한 채움(solid)으로, 겹친 구역은 같은 레벨 색의 연한 태그로 이어 붙인다. "겹침" 글자 라벨은 쓰지 않는다. 태그 단위로 줄바꿈한다.
- [ ] 겹침이 없으면(확인 완료) 태그 하나만 보인다(사용자 결정 2026-11-18: "없음" 문구는 생략해도 인지된다). 확인 중에는 없음으로 단정하지 않고(`겹침 확인 중…`), 일부 조회 실패는 밝힌다.
- [ ] 카드 제목은 주소(도로명, 없으면 지번·행정구역)다. 조회 중·못 찾음·실패는 문구로, 주소 상태가 없으면 "공역 안내". 지번이 있으면 본문에 작은 보조 줄로 보인다.
- [ ] 레벨 안내(금지/제한/가능/없음)는 레벨 색 띠 한 덩어리로 보인다(제목 문구 + 설명).
- [ ] 범례에서 숨긴 구역이면 최상위 태그 옆에 작은 "(범례에서 숨김)"을 보인다.
- [ ] 구역이 없는 클릭(`zoneType: null`)은 태그 줄 없이 회색 띠 안내만 보인다.
- [ ] 카드 높이가 늦게 도착하는 정보로 변하지 않도록 태그 줄(22px)과 지번 줄 자리를 미리 잡는다. 카드 폭 고정(`w-60`)과 0×0 앵커 구조는 유지한다.

## 엣지케이스

- [ ] 긴 주소는 제목 영역에서 말줄임하고 전체는 `title` 속성으로 보인다.
- [ ] 알 수 없는 구역 라벨은 레벨 색 없이 기본 태그/회색 띠로 보인다.
- [ ] 겹친 구역이 많아 태그가 두 줄 이상이면 위로 자란다(허용).

## 범위 밖

- 주소 복사 버튼, 아이콘 추가 등 부가 기능. 승인 불필요 판정(#76).
