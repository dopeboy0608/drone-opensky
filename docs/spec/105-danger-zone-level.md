# 스펙: 위험구역 분류를 비행 제한으로 변경 (#105)

## 배경/목적

국토부 원스톱 범례는 위험지역을 비행금지구역(빨간 테두리)과 별개 종류로 두고 민트색으로 표시한다(2026-11-21 육안 확인).
우리 앱은 위험구역(`lt_c_aisdngc`)을 '비행 금지'(빨강)로 분류해 지도 색과 클릭 안내("원칙적으로 비행이 금지된 구역")가
국토부와 다르다. 법적 분류는 확정하지 못했으며, 국토부 표기를 기준으로 '비행 제한'으로 내린다(사용자 결정).

## 입력

- `ZONE_TYPES`의 `lt_c_aisdngc` 레벨

## 기대 동작

- [ ] `lt_c_aisdngc`의 레벨은 `restricted`다.
- [ ] `prohibited` 그룹은 `lt_c_aisprhc`, `lt_c_aistemp`만 가진다. `restricted` 그룹은 `lt_c_aisdngc`로 시작한다.
- [ ] typename 우선순위(전체 순서)는 바뀌지 않는다.
- [ ] 위험구역 클릭 안내는 '비행 제한' 문구로 나온다(`ZONE_LEVEL_BY_LABEL`에서 파생).

## 엣지케이스

- [ ] 범례 그룹 체크박스와 개별 체크박스가 같은 12종을 본다(기존 순서 일치 테스트 유지).
