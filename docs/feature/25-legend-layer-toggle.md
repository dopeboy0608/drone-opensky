## 조사 결과 (Findings)

- 교차 검증 게이트: ①/② 없음, 디자인 파일 없음(n/a). 통과.
- ③ "좌측 하단 범례 버튼"은 코드에 없음 → 신규 구현 항목(01).
- ③ 폴리곤은 `AirspacePolygonLayer`에서 그룹(`config.level`) 단위로 그리고 `selectedZone` 상태도 레이어 안에 있음 → FR-005를 위해 이 파일 수정 필요(02).
- 미확인: 좌측 하단 카카오 로고와의 겹침 (01 확인 시나리오에 포함).
- 미결(비차단) 1: 코멘트의 "국토부와 동일" — 현 3색이 이미 같다는 뜻인지, 국토부의 종류별 색·패턴을 따르라는 뜻인지. 후자면 별도 이슈.
- 미결(비차단) 2: 코멘트의 "폴리곤 평탄화 제거 및 멀티폴리곤 적용" — 코드에 `flatten`은 없음. `multiPolygonToKakaoPaths`의 MultiPolygon 분해를 가리키는지, 12종→3색 병합을 가리키는지 확인 필요. 이번 이슈에서 렌더링 방식은 바꾸지 않음.
- 미결(비차단) 3: 복구용 "전체 선택" 버튼 추가 여부 (03 착수 전 결정).
